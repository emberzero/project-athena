# Module 99 - Other

This module contains additional workshops, special topics, and supplementary materials that complement the main curriculum modules.

## Topics Covered

- CTF (Capture The Flag) Basics Workshop
- Additional cybersecurity training materials
- Specialized workshops and practical sessions

## Learning Objectives

- Understand how to use CTFs in cybersecurity education
- Explore various CTF platforms and tools
- Gain hands-on experience with practical security challenges
- Learn best practices for integrating CTFs into classroom teaching

## Structure

This module is organized around workshop-style content and special topics that don't fit into the core curriculum modules but provide valuable supplementary learning experiences.
