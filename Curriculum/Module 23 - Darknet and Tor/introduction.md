# Darknet and Tor

This module explains what the darknet actually is, how the Tor network provides anonymity, and where that anonymity ends. Students learn how onion routing and onion services work at the protocol level, why journalists, activists and ordinary users depend on them, and how criminal marketplaces and ransomware groups use the same technology. Most of the second half covers how anonymity fails: traffic correlation, malicious relays, browser exploits and, above all, operational security (OPSEC) mistakes. It draws on real takedowns such as Silk Road, AlphaBay and Hansa.

The module covers the technology and the security work around it. It does not teach how to buy, sell or hide anything, and no assignment requires visiting a darknet marketplace.

## Learning Objectives

- Distinguish the surface web, the deep web and darknets, and name the main darknet technologies (Tor, I2P, Hyphanet)
- Explain how onion routing, circuits, guard/middle/exit relays and the directory system work together
- Describe how v3 onion services are addressed and how the rendezvous protocol hides both client and server
- Identify what Tor protects against and what it does not
- Analyse real deanonymization cases and the technical or OPSEC failures behind them
- Explain how defenders and threat-intelligence teams monitor darknet sources legally and safely

## Topics Covered

1. Introduction to the Darknet
   - Surface web, deep web, darknet
   - History of onion routing
   - Legitimate and criminal use
   - Legal situation in Austria and Germany
1. How Tor Works
   - Onion routing and layered encryption
   - Circuits, relays and directory authorities
   - Bridges and pluggable transports
   - Threat model and limits
1. Onion Services
   - v3 onion addresses
   - Introduction points and rendezvous
   - What runs on onion services
1. Deanonymization and OPSEC
   - Attacks on the network and on the user
   - Case studies: Silk Road, AlphaBay, Hansa, Freedom Hosting
   - Tails, Whonix and other hardening tools
   - Darknet monitoring for defenders

## Prerequisites

- Networking basics (IP, TCP, TLS, DNS)
- Module 01 (Ethics and Legal), in particular the criminal-law sections
- Helpful: Module 02 (Reconnaissance / OSINT) and Module 14 (Cryptography)

By the end of this module, students should be able to explain how Tor anonymizes traffic, judge realistically what it can and cannot hide, and analyse why well-known darknet operators were caught.
